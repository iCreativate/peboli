# MESH — AI Automation Agency

**Brand promise:** AI systems that run your operations while your team sleeps.

MESH is an AI automation agency site for custom agents, workflow automation, and systems integration.

## Tech stack

- Next.js 16 (App Router) + TypeScript
- Tailwind CSS v4 + Framer Motion
- Syne + Manrope typography

## Pages

| Route | Purpose |
|-------|---------|
| `/` | Agency landing |
| `/services` | Service detail |
| `/work` | Case outcomes |
| `/contact` | Discovery brief form |

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
